#    Engenheiros da Pesca

O Engenheiros da Pesca é uma plataforma digital completa voltada para pescadores e
amantes da pesca. O objetivo é unir uma loja online de equipamentos com informações
técnicas sobre espécies de peixes, pesqueiros e conteúdos educativos, tudo em um único
lugar.

#  Funcionalidades
Loja online com equipamentos e acessórios para pesca
Catálogo de espécies de peixes brasileiras
Área do usuário com perfil

# Tecnologias Utilizadas
HTML — Estruturação semântica e acessível da aplicação.
PHP — Guardar as informações de login, conforme ele navega no site.
CSS — Design moderno, responsivo e de rápida estilização.
JavaScript — JS básico para funcionamento melhor do site.
